# About project 

The Velib’ service implemented by the City of Paris is a privileged observatory of soft
urban mobility in the French capital. By combining open real-time Velib’ availability data
with topographical and geographical information, this paper aims to analyze the dynamics
driving station traffic according to the time of day. It lays the foundations for the implemen-
tation of a predictive model, enabling service improvements to make shared bicycle usage
more fluid and comfortable for users.
The data used was acquired over the period of November and December 2025.
In this study, we utilize tools for statistics, modeling, and cartographic visualization. This
article constitutes the final assignment for the Advanced Data Analysis with Python course
taught during the first semester of the 2025/2026 academic year at Sciences Po Paris.
